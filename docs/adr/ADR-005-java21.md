# ADR-005

# Title

Java 21 as LTS Version

---

## Status

Accepted

---

## Context

The project aims to use modern Java features.

---

## Decision

Use Java 21 LTS.

Main features:

- Records
- Pattern Matching
- Virtual Threads (future)
- Sequenced Collections
- Performance improvements

---

## Consequences

The project remains aligned with the current Java ecosystem.
