# ADR-002

# Title

Domain-Driven Design

---

## Status

Accepted

---

## Context

Business rules are expected to evolve over time.

The architecture should keep the domain isolated and expressive.

---

## Decision

The project adopts Domain-Driven Design.

Main concepts:

- Entities
- Value Objects
- Domain Services
- Aggregates
- Repositories
- Ubiquitous Language

---

## Consequences

Positive:

- Rich domain model
- Clear business language
- Easier evolution

Negative:

- Learning curve
